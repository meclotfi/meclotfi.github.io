# Lotfi Abdelkrim Mecharbat

Personal academic website.

Live website: https://meclotfi.github.io

## Updating

Edit the HTML, CSS, JavaScript, and assets in this repository. Push to `main` to publish through GitHub Pages. Pages should deploy from the root of `main`. No build step is required.

## Local preview

Run `python3 -m http.server 4173` in this directory, then open http://localhost:4173.

The original papers, posters, photographs, and institution logos retain their respective rights.
